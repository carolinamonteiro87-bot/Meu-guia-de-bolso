Comando Essenciais



Git init

Serve para adicionar um repositorio (local) dentro da pasta do seu projeto

Git add .

Serve para preparar as alterações feitas nos arquivos do projeoto para serem salvas no próximo historico

Git commit -m "[mensagem do git]"

Serve para salvar as alterações do seu código no histórico do repositório local

git push u- origin

Enviar os commits do seu repositório local para um repositório remoto

Git branch

Cria, lista ou exclui ramificações (branches)

Git checkout ou Git switch

Alterna entre diferentes ramificações

Git fetch

Baixa as atualizações mais recentes de um repositório remoto sem alterar ou mexer no seu código e diretório de trabalho local

Git Pull

Baixa as alterações mais recentes de um repositório remoto (como o GitHub) e as junta imediatamente com o seu código local

Git clone

copia um repositório inteiro de um local remoto (como o GitHub) para o seu computador

Dica: Verifique se o comando está escrito corretamente.
